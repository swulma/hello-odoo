# Hello Odoo – Notes Management Module

A custom notes management module developed for **Odoo 19 Community** as a practical learning project.

## Features
- Create, view, edit, and delete notes.
- Store note titles, content, and creation dates.
- List, form, and search views.
- Menu navigation and window actions.
- Access control rules for internal users.

## Technologies
- Odoo 19 Community
- Python
- XML
- PostgreSQL
- Git and GitHub

## Module Structure
- `models/`: Python data models.
- `views/`: XML user interface views.
- `security/`: Access control configuration.
- `__manifest__.py`: Module metadata and data files.

## Installation
1. Copy the `hello_odoo` directory into an Odoo custom addons directory.
2. Add the directory to Odoo's `addons_path`.
3. Restart the Odoo server.
4. Update the Apps list.
5. Search for **Hello Odoo** and install the module.

## Purpose
This project demonstrates the fundamentals of Odoo module development, including Python models, XML views, menus, actions, and access control.
